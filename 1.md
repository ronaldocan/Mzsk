
### 接口描述

用户H5登录

### 请求地址

| **环境** | **请求地址**             |
| -------- | ------------------------ |
| url      | /cms/customer/h5/getToken/ |

### 请求方法

POST

### 请求参数

### 公共请求参数（Header传参）

| 名称         | 类型   | 必须 | 描述                                                         | 示例值                           |
| :----------- | :----- | :--- | :----------------------------------------------------------- | :------------------------------- |
| request_id   | string | 否   | 每次请求生成32位字符的唯一id，**保证每次请求的request_id不一样** | 4e770f101c9a4191bfd4609d26c6e0bd |
| access_token | string | 是   | 应用访问接口token                                            | 5e770f101c9a4191bfd4609d26c6e0bd |
| method       | string | 是   | 接口名称                                                     | cms.customer.h5.getToken         |
| version      | string | 是   | 版本号                                                       | 1.0                              |
| timestamp    | string | 是   | 时间戳，格式为yyyy-MM-dd HH:mm:ss，时区为GMT+8。服务端允许客户端请求最大时间误差为10分钟 | 2020-11-01 13:44:11              |
| sign         | string | 是   | 请求参数的签名串 ， [签名算法介绍](http://192.168.5.53/index.html#/help?id=sign) | xxxx                             |

### 业务请求参数（Body传参JSON数组格式）

| 名称         | 类型   | 必须 | 最大长度 | 描述                                                   | 示例值 |
| :----------- | :----- | :--- | :------- | :----------------------------------------------------- | :----- |
| customerCode | string | 是   |    -      | 融资端外部客户编码                                     |     -   |
| backLink     | string | 是   |     -     | 页面URL（用于返回外部系统）                            |     -   |
| type         | int    | 否   |      -    | 跳转（唤起）类型 0：首页 1：订单详情 ； 不传默认到首页         |       - |
| id           | string | 否   |     -     | 订单id ，type为1时必传，订单编号跳转到对应的订单详情页 |      -  |
| productCode  | string | 否   |    -      | 产品id，type为0时必传，产品编号跳转到对应的银行产品页  |     -   |
| safeAreaTop  | int    | 否   |    -      | 安全区域高度，处理手机状态栏遮挡，具体看手机测算高度   |      -  |
| appTitle  | string    | 否   |    -      | H5首页标题，不传值默认明心字样，有值页面显示对应的值   |      -  |

### 响应参数（JSON格式）

### 公共响应参数

| 名称     | 类型   | 描述                       | 示例值              |
| -------- | ------ | -------------------------- | ------------------- |
| code     | string | 返回码                     | 40002               |
| msg      | string | 返回信息                   | 非法的参数          |
| sub_code | string | 请求失败返回的子错误码     | isv.invalid-app-key |
| sub_msg  | string | 请求失败返回的子错误信息   | 无效的app-key参数   |
| data     | json   | 请求成功返回的业务响应参数 |           -          |

### 业务响应参数

| 名称      | 类型   | 必须 | 最大长度 | 描述                         | 示例值 |
| --------- | ------ | ---- | -------- | ---------------------------- | ------ |
| loginLink | string | 是   | -        | 返回H5链接（带账期登录标识） |    -    |

### 响应示例

```json
{
    "code": "10000",
    "msg": "success"
}
```

### 错误示例

```json
{
    "code": "40004",
    "msg": "业务处理失败",
    "sub_code": "isv.name-error",
    "sub_msg": "融资企业未接入"
}
```
